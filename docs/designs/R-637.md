  button: an outlined pill with a clock, "Rest 2:00" (or "Rest off"), and a small pencil. The row starts at the card's left
  edge (under the picture, not indented).

  workout: "Previous: 3 Oct · Legs B" (owner, 28 Nov 2026: "First time here can go ... date and then ... the name"). The

  no name → "Previous: 3 Oct").

- Sees (superset): the "Superset A" chip first, then the source text, then the rest button. Tapping the chip opens the
  superset sheet, as today.
- Sees (custom rest for this exercise): the rest button's border and text in the accent colour, as today's text colour.
- Sees: tapping the rest button opens the same rest picker as today (sheet 'rest').
- Sees (••• menu): one info line at the top, not a button: "Body part" with the muscle label (exercise.muscleLabel, else the

  2026: "the history can also go from the menu").
- Sees (editing a finished workout): no rest button (as today: rest is hidden when editing); source text as above; menu as
  above (it already had no rest row when editing).
- Sees (compact drag state): unchanged (only the name row).
- Sees (largest text, 360 dp phone): the source text is one line ending with "…" when it does not fit; the rest button never
  wraps under it and never shrinks below its text.
- Must NOT see: the body-part chip on the card.
- Must NOT see: a "Rest timer" row in the ••• menu.
- Must NOT see: "Last:" anywhere on the card or in the menu (owner rule: "Previous", never "Last", where the sets are).
- Must NOT see: the row indented past the picture.
