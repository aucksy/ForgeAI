## Limits of this file (what it cannot say)

- **Flow level**: not in the API. See "Phone and browser flows" above for the runs E2 must read.
- **Flaky candidates are a floor, not the real count.** A push run tests a new commit every time and is rarely
  re-run, so a random fail on a push can only show up as "Alone" (a hint). Hand-started phone runs only match
  when the run title (parts, phone, extras) is the same.
- **Cancelled jobs** (405 job rows) are not counted as fails. The API does not say why a job was cancelled: by hand, by a newer
  round replacing it, by a sibling shard failing first (fail-fast), or by a time limit. No job in the window has the result `timed_out`.
- **Minutes** are job start to job end. They are not the billed minutes and leave out time waiting for a runner.
- **Runs with no job rows**: ci.yml failure x1; ci.yml in_progress x4; ios.yml cancelled x5; qa-device.yml failure x1; wear-build.yml cancelled x3. Counted as runs; they have no minutes.
- **test-lab.yml**: 0 runs in the window.
