# ForgeAI desk cheat sheet — one page, keep at the desk (launch plan G2)

Bottom menu: **Today · Members · Money · Visits · More**. Print in A4, both languages.

| Job | Do this | हिंदी |
|---|---|---|
| Check a member in | **Visits** → type the name or last 4 digits of the mobile → **Check in** | Visits → नाम या मोबाइल के आखिरी 4 अंक → Check in |
| New member | **Members** → **Add member** (name, mobile) → **Sell membership** | Members → Add member → Sell membership |
| Renewal | Open the member → **Renew** → plan → amount received → **Confirm** | मेंबर खोलें → Renew → प्लान → मिली रकम → Confirm |
| Part payment / dues | Open the member → **Collect payment** → amount → **Save payment** | मेंबर खोलें → Collect payment → रकम → Save payment |
| Who owes money | **Money** → **Dues** (or the **Fees due** tile on Today) | Money → Dues |
| Whose plan ends soon | **Today** → **Ending in 1-3 / 4-7 / 8-15 days** tiles | Today → Ending in … टाइल |
| Wrong receipt (owner only) | Open the receipt → **Cancel receipt** → write the reason. Never re-use its number | रसीद खोलें → Cancel receipt → कारण लिखें (सिर्फ मालिक) |
| Print or send a receipt | Open the receipt → print, or send on WhatsApp | रसीद खोलें → प्रिंट या WhatsApp |
| Shop order | **Today** → **Shop today** → **Open shop** → mark ready, then collected | Today → Shop today → Open shop |
| End of day | **Money** → today: cash + UPI must match the drawer and the UPI app | Money → आज: कैश + UPI मिलाएँ |

**Something broken?** Write it on paper (name, amount, time), carry on, and message the WhatsApp
support group with a photo of the screen. Never enter a payment twice to "test".

Button names checked against the admin app code, 19 Oct 2026.
